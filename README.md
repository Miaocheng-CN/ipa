# 清影 iPad 1.1.36
适用 iPadOS 17 或以上。这里提供的是 Xcode 源工程，不含已签名的 IPA。
## 漫画
首页 → 漫画书架 → 进入章节 → 轻点画面 → 阅读设置。可选连续下滑、单页翻页或双页并排，翻页动效可单独关闭。双页推荐横屏；左右滑动或点箭头翻页；单数末页单独显示，再向前翻进入下一章。设置和阅读进度在本机保存。
## 影视与播放队列
从首页的「更多」打开雷霆大列表，或从影片详情加入季/集；可调整顺序、指定接下来播放的集数。播放器还包括观看历史、跳片头片尾、手动广告区间、画中画和下载入口。小游戏在「更多」里。漫画数据跨端同步和安卓终端不在此版本的功能范围内。线上片库、封面、播放线路和漫画源受站点可用性影响，不能保证与 Android 的每一条线路一致。
## 在 Mac 构建
解压后，在安装了完整 Xcode 及 iOS SDK 的 Mac 打开终端进入本目录，执行：
    bash Build-iPad.command
成功后，输出 build/Qingying-iPad-1.1.36-unsigned.ipa。此文件需要用自己的 Apple 开发签名后才能安装。也可以直接用 Xcode 打开 Qingying.xcodeproj，在 Signing & Capabilities 选择自己的 Team；如标识被占用，需要改为自己的唯一标识，再选择 iPad 运行。
## 验证范围
阅读交互用本地测试章节验证，包含单双页、奇数末页、跨章、重开续读及连续模式。Tests/reader_fixture.py 提供同类浏览器回归测试（Python、Playwright 和 Chromium）。当前交付未经 Xcode 编译或 iPad 真机验收。
